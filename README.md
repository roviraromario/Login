# Login Validation System

## Description

This project is a Python login validation program.
It is a simple script that checks if the email and password entered by the user are valid.

## How it works

1. The program asks the user to enter a username.
2. It asks the user for an email.
3. The program checks if the email contains "@" and ".".
4. It verifies if the email starts with invalid characters.
5. The program asks the user for a password.
6. It checks if the password has at least eight characters.
7. The program verifies if the password contains numbers and uppercase letters.
